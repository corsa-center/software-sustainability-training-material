5.6. Material and covered topics (_Note that each set of material considers its own categories of topics, and these are inconsistent and overlapping._) 

  * [INTERSECT](https://intersect-training.org/training-links/)  
    * Building a community, CI/CD, Code Review, Collaborative Git, Documentation, Issue tracking, Licensing, Making good PRs, Packaging, Project Management, Software design, Testing  
  * [Software carpentry](https://software-carpentry.org/lessons/)  
    * Unix shell, Git, Programming with Python, Programming with R, Automation and make, Programming with Matlab, Using databases and SQL  
  * [Code Refinery](https://coderefinery.org/lessons/)  
    * Version control and collaborative version control, reproducible research, Social coding and open source, documentation, use of AI in coding, testing, modularity, HPC resources/work/containers/parallelization/workflows, CMake, mixed languages  
  * [URSSI School, including the June 2026 instance](https://github.com/si2-urssi/summerschool-June2026)  
    * Environments, software design and modularity, structuring Python packages, collaboration with Git & GitHub, testing & CI & linting, peer code review, documentation & versioning, open science & software citation  
  * [UNIVERSE-HPC](https://www.universe-hpc.ac.uk/resources/training-material/)  
    * Software architecture & design (procedural, OO, functional programming), Tech & tooling (shell, version control, packaging & dependency management, best practices, IDEs, testing, containerization, snakemake), Software project management (collaboration on GitHub, CI), HPC (scalability, profiling), intro to python   
  * [IDEAS-productivity](https://ideas-productivity.org/resources/tools-and-practices.html)  
    * Productivity and Sustainability Improvement Planning (PSIP)  
    * [Most recent full-day BSSw tutorial](https://bssw-tutorial.github.io/2025-08-08-atpesc/)  
      * Software design, Spack package management, testing & verification, refactoring software, software licensing, reproducibility  
  * [S<sup>3</sup> School](https://indico.in2p3.fr/event/36319/)  
    * Open & reproducible science, environment, good code practices, project structure, Git & GitHub, debugging, unit tests, integration tests, CI/CD, profiling & optimization, AI-assisted development, containerization, security, documentation, quality, software publication  
  * [The Turing Way](https://book.the-turing-way.org/) (code-related parts)  
    * Documentation, quality, testing, core review, reusable code, CI, make, project design, repositories  
  * [Netherlands eScience Center ](https://www.esciencecenter.nl/training-materials/)  
    * Reproducible research with R packages, GPU programming, Introduction to Deep Learning, Geospatial Python, Medical Image Processing, Natural Language Processing, Research Software support (FAIR, licensing, citation, testing, SMPs), Efficient computing with Julia, Good practices in research software development, collaborative version control with Git/GitHub, Intermediate research software development, AI-assisted coding with Codeium/Copilot, Machine Learning in Python with Scikit-learn, Parallel programing, Reproducible research through reusable code  
  * [ARCHER2](https://www.archer2.ac.uk/training/)  
    * MPI, OpenMP, Intro to HPC, Data analysis and visualization in Python, Modern C++ for computational scientists, Efficient Parallel IO, Containers (Podman, Apptainer), GPU programming with kernels, GPU programming with directives, Green software use on HPC  
  * [Aalto University's Scientific Computing in Practice](https://scicomp.aalto.fi/training/) (site-specific)
    * HPC Kickstart, Linux shell, MPI and OpenMP, Data Analysis with R, Python, Matlab, Containers on HPC (Apptainer)  
  * [Princeton Research Computing](https://researchcomputing.princeton.edu/learn) (site-specific)
  * [Oxford RSEng Group](https://www.rse.ox.ac.uk/training) (site-specific)
  * [MolSSI education](https://education.molssi.org/) (site-specific)
  * [UCL RSEng course](https://github-pages.ucl.ac.uk/rsd-engineeringcourse/)  
  * [MIT's missing semester](https://missing.csail.mit.edu/)
