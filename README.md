# Software sustainability training material
This repository is intended to be a place to collect and share and collaborate on material that can be used for software sustainability training.

## Introduction 

This repo was initially developed by the [CORSA](https://corsa.center) project, primarily [Daniel S. Katz](https://github.com/danielskatz), with other authors/contributors to be indicated in [AUTHORS.md](AUTHORS.md).

It's intended for multiple audiences:
* people interested in developing or delivering training on software sustainability
* people interested in learning about software sustainability
* people interested in researching software sustainability

These audiences could include OSPOs/[CURIOSS](https://curioss.org), RSE groups, [The Carpentries](https://carpentries.org), technology transfer offices, entrepreneur programs, etc.

It contains
* A way to organize material that can be used to train or learn about software sustainability, as
  * Section
    * Areas within the section
      * Topic(s) within the area
      * Source(s) of material for the area
* [A list of sources of material](sources.md)

Sections:
  * [1. Introduction to software sustainability](intro.md)
  * [2. Governance](governance.md)
  * [3. Community](community.md)
  * [4. Funding](funding.md)
  * [5. Software engineering](se.md)
  * [6. Working with (computing) facilities](facilities.md)

We know it's not complete, but we hope it's useful as is, and that others will improve it by adding more topics and resources, fixing any errors, trying it out and reporting what is learned, etc.
